# Disable Enemies Shared Library

This is a *Factorio* mod serving as a shared library for other mods that selectively disable specific types of enemies.

## Overview

Do you wish you could disable *some* enemies, but the "No enemies" setting for new maps goes too far, disabling *all* enemies—and on *all* planets, if playing with Space Age?

This mod provides the core functionality for stopping the spawning of some enemies while letting other enemy types continue to spawn normally.

## Features

- Selectively disable enemies from spawning from unit spawners.
- Configure whether disabled enemies are substituted in their evolution-based spawn rates by alternative enemies that remain enabled (to avoid periods of unusually low spawn rates).
- Disable items from spawning enemies when they spoil.
- Disable projectiles from spawning enemies when they hit.
- Disable projectiles from spawning enemies when they kill their target.
- Disable entities from spawning enemies when they take damage.
- Disable entities from spawning enemies when they die.
- Disable the attack of turret entities.
